# Shopping Website UI

A simple shopping website interface built using HTML, CSS, and JavaScript.  
This project dynamically fetches product data from the Fake Store API and displays it in a product grid layout.

## 🚀 Features
- Fetches product data using JavaScript Fetch API
- Displays product image, category, price, and rating
- Responsive product grid layout
- Uses Fake Store API for dynamic product data

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Fake Store API
